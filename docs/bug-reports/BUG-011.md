# BUG-011

**Заголовок:** Образ web содержит 44 известные уязвимости уровня High в системных пакетах

**Окружение:** GitHub Actions, Trivy (aquasecurity/trivy-action 0.36), образ `kanban-web` на базе `nginx:1.29-alpine`

**Чем найден:** сканирование образов Trivy в CI (задача «Security scan»)

**Шаги:**

1. Собрать образ `docker compose build web`.
2. Выполнить `trivy image --severity HIGH,CRITICAL --ignore-unfixed kanban-web:local`.

**Ожидаемый результат:** Нет уязвимостей High и Critical, для которых выпущены исправления.

**Фактический результат:** `Total: 44 (HIGH: 44, CRITICAL: 0)` — устаревшие пакеты Alpine в базовом образе (например, `c-ares` 1.34.6-r0 с CVE-2026-33630, исправлено в 1.34.8-r0).

**Severity:** Major

**Priority:** High

**Вложение:** журнал задачи «Security scan», шаг «Trivy web image»

**Статус:** исправлен — базовый образ заменён на `nginx:1.29-alpine-slim` (без лишних модулей), при сборке выполняется `apk upgrade`; повторный скан: 0 уязвимостей.

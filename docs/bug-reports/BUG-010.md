# BUG-010

**Заголовок:** Карточку нельзя открыть с клавиатуры

**Окружение:** Chrome 156 (Playwright 1.64), Linux, Docker Compose

**Чем найден:** E2E-тест «карточку можно открыть с клавиатуры» (`e2e/tests/usability.spec.ts`)

**Шаги:**

1. Открыть доску с карточкой.
2. Перейти к карточке клавишей Tab.
3. Нажать Enter.

**Ожидаемый результат:** Открывается диалог карточки.

**Фактический результат:** Диалог не открывается: датчик клавиатуры dnd-kit по умолчанию начинает перетаскивание по Enter и отменяет событие.

**Severity:** Major

**Priority:** Medium

**Вложение:** снимок страницы из отчёта Playwright — диалог отсутствует после нажатия Enter

**Статус:** исправлен — перетаскивание с клавиатуры назначено на Пробел, Enter открывает карточку (`frontend/src/pages/BoardPage.tsx`).

# BUG-007

**Заголовок:** Слишком большой запрос получает ответ 401 вместо 413

**Окружение:** Интеграционные тесты: сервер в httptest, PostgreSQL и Redis в testcontainers

**Чем найден:** интеграционный тест `TestUnknownRoutesAndHeaders`

**Шаги:**

1. Войти.
2. Отправить `POST /api/v1/projects` с телом JSON больше 1 МиБ.

**Ожидаемый результат:** `413` с кодом ошибки, понятным клиенту.

**Фактический результат:** `401 UNAUTHORIZED «Требуется аутентификация»`: валидатор OpenAPI читает тело при проверке безопасности, ошибка чтения превращалась в ошибку аутентификации.

**Severity:** Minor

**Priority:** Low

**Вложение:** `security requirements failed: reading failed: http: request body too large`

**Статус:** исправлен — ошибка превышения размера распознаётся первой и отдаётся как `413 PAYLOAD_TOO_LARGE`; коммит `2e4630a`.

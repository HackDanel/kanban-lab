# BUG-009

**Заголовок:** Некорректный идентификатор в пути возвращает ошибку не в формате API

**Окружение:** Интеграционные тесты, сервер Go

**Чем найден:** интеграционный тест `TestProjectVisibility`

**Шаги:**

1. Выполнить `GET /api/v1/projects/not-a-uuid` с токеном.

**Ожидаемый результат:** `400` в формате `{"code": "VALIDATION_ERROR", "details": [{"field": "projectId", …}]}`.

**Фактический результат:** `400` с текстом `Invalid format for parameter projectId: …` — клиент не может разобрать ответ как JSON.

**Severity:** Minor

**Priority:** Medium

**Вложение:** `body: Invalid format for parameter projectId: error unmarshaling 'not-a-uuid' text as *uuid.UUID`

**Статус:** исправлен — обработчик ошибок привязки параметров генерированного роутера и проверка формата `uuid` в валидаторе; коммит `2e4630a`.

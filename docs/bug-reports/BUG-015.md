# BUG-015

**Заголовок:** Время ответа списка карточек растёт со смещением страницы

**Окружение:** Docker Compose, PostgreSQL 17, доска с 10 000 карточек; k6 в контейнере на той же машине

**Чем найден:** нагрузочный тест `tests/load/rps.js` (постоянные 1000 запросов в секунду, листание колонки со смещением до 3000)

**Шаги:**

1. `make load-rps`

**Ожидаемый результат:** 1000 запросов в секунду без пропусков, p95 меньше 200 мс.

**Фактический результат:** 978 запросов в секунду, p95 = 940 мс, 1397 итераций пропущено. Страница выбиралась прямо из представления `card_views`, которое для каждой строки вычисляет метки, число комментариев и вложений подзапросами. При `OFFSET 2950` эти подзапросы выполнялись для всех 3000 строк, а не для 50 возвращаемых.

**Severity:** Major

**Priority:** High

**Вложение:** `tests/load/results/rps-final.txt`

**Статус:** исправлен — сначала по индексу выбираются идентификаторы страницы, затем только они соединяются с представлением (`backend/internal/repository/cards_search.go`). Повторный прогон: 990 запросов в секунду, p95 = 5,9 мс, без ошибок и пропусков.

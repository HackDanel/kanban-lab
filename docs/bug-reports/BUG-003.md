# BUG-003

**Заголовок:** Страницы приложения отдаются без заголовков безопасности (CSP, X-Frame-Options)

**Окружение:** Docker Compose: nginx 1.29 (контейнер web), curl 8

**Чем найден:** ручная проверка заголовков ответа

**Шаги:**

1. Поднять стек `docker compose up`.
2. Выполнить `curl -sI http://localhost:8000/`.

**Ожидаемый результат:** В ответе есть `Content-Security-Policy`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`.

**Фактический результат:** Заголовков нет. В `location /` задан собственный `add_header Cache-Control`, а nginx в этом случае не наследует директивы `add_header` уровня `server`.

**Severity:** Major

**Priority:** High

**Вложение:** вывод `curl -sI` без строк `Content-Security-Policy` и `X-Frame-Options`

**Статус:** исправлен — заголовки вынесены в `frontend/security-headers.conf` и подключаются в каждом `location` со своими `add_header`; коммит `ab82d6b`.

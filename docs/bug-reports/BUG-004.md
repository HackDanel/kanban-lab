# BUG-004

**Заголовок:** Загрузка вложения в Docker-стеке завершается ошибкой 500

**Окружение:** Chrome 156 (Playwright 1.64), Linux, Docker Compose; образ backend на distroless:nonroot

**Чем найден:** E2E-тест TC-22 «вложения загружаются и скачиваются»

**Шаги:**

1. Войти менеджером, открыть карточку.
2. Вкладка «Вложения» → «Прикрепить файл» → выбрать `notes.txt`.

**Ожидаемый результат:** Файл появляется в списке вложений.

**Фактический результат:** Сообщение «Внутренняя ошибка сервера». Том `uploads` создавался с владельцем root, а сервер в контейнере работает от пользователя nonroot.

**Severity:** Critical

**Priority:** High

**Вложение:** лог сервера: `"msg":"request failed","path":"/api/v1/cards/…/attachments","err":"save file: open /data/uploads/.upload-3750304760: permission denied"`; снимок страницы из отчёта Playwright: `alert: Внутренняя ошибка сервера`

**Статус:** исправлен — в `backend/Dockerfile` каталог `/data/uploads` создаётся в образе с владельцем 65532 (nonroot), новый том наследует права; коммит `5caf94e`.

# BUG-008

**Заголовок:** Неизвестные поля в теле запроса молча игнорируются

**Окружение:** Интеграционные тесты, сервер Go

**Чем найден:** интеграционный тест `TestCreateCardValidation`

**Шаги:**

1. Отправить `POST /api/v1/columns/{id}/cards` с телом `{"title": "x", "extra": true}`.

**Ожидаемый результат:** `400 VALIDATION_ERROR`: опечатка в имени поля не должна теряться незаметно.

**Фактический результат:** `201`, поле `extra` проигнорировано.

**Severity:** Minor

**Priority:** Low

**Вложение:** тело ответа 201 из вывода теста

**Статус:** исправлен — `additionalProperties: false` для всех входных схем в `api/openapi.yaml`; коммит `2e4630a`.

# BUG-002

**Заголовок:** Поиск и фильтры доски возвращают пустой список, если не выбрана ни одна метка

**Окружение:** Локальный сервер (Go 1.27), PostgreSQL 17 в Docker

**Чем найден:** ручной сквозной прогон API скриптом

**Шаги:**

1. Создать доску и две карточки, одна с названием «Second …».
2. Выполнить `GET /api/v1/boards/{id}/cards?q=sec`.

**Ожидаемый результат:** В ответе карточка «Second …», `total: 1`.

**Фактический результат:** `{"items": [], "total": 0}` для любого запроса без параметра `labelId`: пустой срез Go передавался в SQL как `NULL`, а `cardinality(NULL) = 0` даёт `NULL`, то есть условие ложно для всех строк.

**Severity:** Critical

**Priority:** High

**Вложение:** ответ сервера: `search: 200 {"items": [], "total": 0}`

**Статус:** исправлен — `COALESCE(cardinality(@label_ids::uuid[]), 0) = 0` в `backend/queries/cards.sql`; регрессионный тест `TestFilterAndSearchCards`; коммит `2e4630a`.

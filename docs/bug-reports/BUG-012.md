# BUG-012

**Заголовок:** Под нагрузкой Nginx не может подключиться к бэкенду: 31,7 % запросов завершаются ошибкой

**Окружение:** Docker Compose (nginx 1.29, backend, PostgreSQL 17), k6 в контейнере на той же машине; Linux, 16 потоков

**Чем найден:** нагрузочный тест `tests/load/crud.js` (1000 виртуальных пользователей, 10 000 карточек)

**Шаги:**

1. `docker compose up -d --build --wait`
2. `make load`

**Ожидаемый результат:** Доля ошибок меньше 1 %.

**Фактический результат:** `failed: 31.73%`. Сервер ответил 2xx почти на все дошедшие запросы (1 ответ 500 из ~128 000), а в журнале Nginx — `connect() to 172.18.0.6:8080 failed (99: Address not available) while connecting to upstream`. Nginx открывал к бэкенду новое TCP-соединение на каждый запрос, закрытые соединения оставались в TIME_WAIT, и эфемерные порты закончились.

**Severity:** Critical

**Priority:** High

**Вложение:** `tests/load/results/crud-local.txt` (сводка k6), фрагмент журнала контейнера web

**Статус:** исправлен — блок `upstream backend { keepalive 128; }`, `proxy_http_version 1.1` и пустой заголовок `Connection` в `frontend/nginx.conf`: соединения к бэкенду переиспользуются.

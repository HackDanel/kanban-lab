# BUG-001

**Заголовок:** При выходе без связи с сервером в консоли появляется необработанная ошибка

**Окружение:** Vitest 5 + jsdom, Node.js 26; локальная сборка фронтенда

**Чем найден:** модульный тест `App.test.tsx` «завершает локальную сессию, даже если сервер не ответил на выход»

**Шаги:**

1. Войти в систему.
2. Отключить сеть (в тесте — ответ `HttpResponse.error()` на `POST /auth/logout`).
3. Нажать «Выйти».

**Ожидаемый результат:** Пользователь выходит из системы; ошибок в консоли нет.

**Фактический результат:** Пользователь выходит, но в консоли — `Unhandled Rejection: {status: 'FETCH_ERROR'}`: в `onQueryStarted` мутации `logout` ошибка `queryFulfilled` выходила наружу через `try/finally` без `catch`.

**Severity:** Minor

**Priority:** Medium

**Вложение:** вывод Vitest: `Vitest caught 1 unhandled error during the test run … Unhandled Rejection … url: 'http://localhost:3000/api/v1/auth/logout'`

**Статус:** исправлен — ошибка перехватывается, локальная сессия завершается в любом случае (`frontend/src/features/auth/authApi.ts`); коммит `267df94`.

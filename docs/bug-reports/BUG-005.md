# BUG-005

**Заголовок:** Доска не обновляется в реальном времени, если приложение открыто на нестандартном порту

**Окружение:** Chrome 156 (Playwright 1.64), Docker Compose, приложение на http://localhost:8000

**Чем найден:** E2E-тест TC-27 «изменения видны в другой вкладке без перезагрузки»

**Шаги:**

1. Открыть одну доску в двух вкладках.
2. В первой добавить карточку.

**Ожидаемый результат:** Карточка появляется во второй вкладке без перезагрузки.

**Фактический результат:** Вторая вкладка не меняется. WebSocket отклоняется с 403: nginx передаёт бэкенду `Host` без порта (`$host`), а заголовок `Origin` браузера — `localhost:8000`; проверка происхождения считает их разными.

**Severity:** Major

**Priority:** Medium

**Вложение:** лог сервера: `"method":"GET","path":"/api/v1/ws","status":403` (38 записей за прогон)

**Статус:** исправлен — `proxy_set_header Host $http_host` в `frontend/nginx.conf`; коммит `5caf94e`.
